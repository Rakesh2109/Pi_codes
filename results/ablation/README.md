# GLADE component ablation

Each of GLADE's stages is disabled in isolation, the binariser is re-fitted, and
the FPTM is re-trained with the per-dataset configuration from the paper
(`n_bins = 15`, `seed = 42`, the `TM_PARAMS_PER_DATASET` config). Generated by
[`paper_2.glade_ablation`](../../src/paper_2/glade_ablation.py):

```bash
cd src
for ds in wustl nslkdd ton_iot medsec; do
  for v in full no_budget no_gap no_perturb; do
    python -m paper_2.glade_ablation --dataset $ds --variant $v \
        --out ../results/ablation/${ds}_${v}.json
  done
done
```

(The historical `*_no_entropy.json` cells were run before Step 3 was removed; on
NSL-KDD/TON_IoT/MedSec they are byte-identical to `full`, on WUSTL the F1 is
slightly higher — which is why Step 3 was dropped.)

## Results (bits / accuracy / macro-F1)

| Configuration | NSL-KDD | TON_IoT | MedSec-25 | WUSTL-EHMS-2020 |
|---|---|---|---|---|
| GLADE (full) | 253 / .9951 / .9356 | 122 / .9708 / .9410 | 351 / .9706 / .8697 | 256 / .9424 / .7736 |
| − Step 1 adaptive budget | **320** / .9952 / .9282 | **152** / .9724 / .9422 | **613** / .9728 / .8797 | 256 / .9424 / .7736 |
| − Step 2 gap-aware placement | 254 / .9947 / **.9233** | 122 / .9705 / .9426 | 351 / .9707 / .8701 | 257 / .9436 / .7879 |
| − Step 3 entropy pruning | 253 / .9951 / .9356 | 122 / .9708 / .9410 | 351 / .9706 / .8697 | 256 / .9421 / .7868 |
| − Step 4 local refinement | 253 / .9950 / .9349 | 122 / .9647 / **.9367** | 351 / .9723 / **.8804** | 256 / .9449 / **.7889** |

## Reading

- **Step 1 (adaptive budget)** — the compactness mechanism. Removing it bloats
  the Boolean vector by +27 % (NSL-KDD), +25 % (TON_IoT), +75 % (MedSec-25) for
  essentially no accuracy gain. *Keep.*
- **Step 2 (gap-aware placement)** — worth ≈1.2 macro-F1 points on NSL-KDD
  (handcrafted TCP/IP features have the most structural gaps); roughly neutral
  elsewhere. *Keep.*
- **Step 3 (entropy pruning)** — never fires: produces byte-identical thresholds
  to disabling it on NSL-KDD/TON_IoT/MedSec, and slightly *hurts* on WUSTL.
  Quantile placement already keeps every bit far from p≈0/1. **Removed.**
- **Step 4 (local refinement)** — clearly helps the largest dataset (TON_IoT,
  −0.6 acc / −0.4 F1 without it); on MedSec/WUSTL removing it *raises* F1 by
  ≈1 point, but WUSTL's test split is only 3 264 rows (within noise). Net
  neutral-to-helpful. *Keep.*
